# Yazim Rehberi (Medium ve YouTube)

## Ton
- Net, samimi, mühendis durustlugu. Abartisiz; "I built / I learned / I measured" dili.
- Kisa cumleler, aktif cati. Jargon kullanirsan ilk geciste acikla.
- Basarisizliklari ve sinirlamalari dahil et; guven bu sekilde kurulur.

## Medium Makale Yapisi
1. **Title:** vaat + somut sonuc (60-70 karakter). Alternatif 3 baslik uret.
2. **Hook (ilk 3 cumle):** problem veya merak uyandiran sonuc.
3. **Why it matters:** okuyucu icin deger.
4. **Approach:** veri, yontem, kritik kararlar (neden bu secildi).
5. **Code / visuals:** yalniz ogretici kod parcalari; tam kod icin GitHub baglantisi.
6. **Results:** baseline vs final, durust yorum.
7. **Lessons and limitations.**
8. **Call to action:** repo, demo, soru daveti.
- Uzunluk: 5-8 dakika okuma. Her 3-4 paragrafta alt baslik veya gorsel.
- Etiketler: 5 adet (ornek: Data Science, Machine Learning, Python, FastAPI, LLM).

## YouTube Senaryo Yapisi
| Bolum | Sure | Icerik |
|---|---|---|
| Hook | 0:00-0:20 | Sonucu veya problemi goster |
| Context | 0:20-1:00 | Neden bu proje, kime fayda |
| Build | 1:00-7:00 | Adim adim, ekran paylasimi |
| Results | 7:00-9:00 | Metrikler, demo, sinirlamalar |
| Outro | 9:00-9:30 | Ozet + CTA (repo, abonelik) |

Senaryo formati: iki sutun (**Voiceover** | **On-screen / B-roll**).

## Ingilizce Kalite Kontrolu
- Gereksiz zarflar ve dolgu ifadeleri sil. Pasif catiyi azalt.
- Teknik terimleri tutarli kullan (model / classifier / estimator karisimi yapma).
- Yazimdan sonra bir kez yuksek sesle okuma testi uygula.
