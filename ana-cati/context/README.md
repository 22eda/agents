| Dosya | Ne zaman okunur |
|---|---|
| `proje-ozeti.md` | Sistemin ne oldugunu / klasor konumlarini hatirlamak gerektiginde |
| `hedefler.md` | Onceliklendirme veya plan yaparken |
| `kurallar-ve-sinirlar.md` | Yetki, guvenlik veya yonlendirme belirsizliginde |

| `kaynaklar/baglantilar.md` | Eda'nin hesaplari, repolari, platform linkleri gerektiginde |
